IP LOCATOR - PORTABLE WINDOWS APPLICATION

Requirements: Windows 10/11, 64-bit (x64), a web browser, and Internet access.

1. Download IP-Locator.exe to a folder you can access.
2. Double-click IP-Locator.exe.
3. Your default browser opens the IP Locator interface.
4. Enter a public IPv4 or IPv6 address and choose Locate IP.
5. Close the IP Locator console window to quit the application.

No installer, administrator access, Node.js installation, or additional files
are required. The executable includes the application and its Node runtime.
The console displays a local-only URL if the browser does not open automatically.
The app binds to 127.0.0.1 on an available port, not to your public network.

Geolocation and map data require Internet access. Locations are approximate.
The app sends queried IP addresses to ipwho.is (or ipapi.co as a fallback),
and map coordinates to OpenStreetMap. It does not store lookup history.

This build is unsigned. Windows or your organization's security tools may
warn about or restrict an unsigned executable. Production signing requires
the distributor's Windows code-signing certificate.
