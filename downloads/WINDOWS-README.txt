IP LOCATOR - PORTABLE WINDOWS APPLICATION

The footer shows your installed version and links to the official Releases page.
Use Copy buttons to copy addresses, ranges, and returned values without opening
them as websites. Public registry/routing links open official information services.
Network ranges (CIDR) are blocks of addresses, not web links.

After a lookup finishes, Print / Save PDF opens a readable report in your browser's
print dialog. Choose Save as PDF if offered. Reports include the app version,
Developed by Justice Floyd credit, lookup time, source states and limitations.

Requirements: Windows 10/11, 64-bit (x64), a web browser, and Internet access.

1. Download IP-Locator.exe to a folder you can access.
2. Double-click IP-Locator.exe.
3. Your default browser opens the IP Locator interface.
4. Enter a public IPv4 or IPv6 address and choose Locate IP.
5. Close the IP Locator console window to quit the application.

No installer, administrator access, Node.js installation, or additional files
are required. The executable includes the application and its Node runtime.
The console displays a local-only URL if the browser does not open automatically.
The app binds to 127.0.0.1 on an available port, not to your public network.

Geolocation and map data require Internet access. Locations are approximate.
The app sends queried IP addresses to ipwho.is and ipapi.co for comparisons,
to Google Public DNS (dns.google) for reverse-DNS hostname clues,
and map coordinates to OpenStreetMap. It does not store lookup history.

This build is unsigned. Windows or your organization's security tools may
warn about or restrict an unsigned executable. Production signing requires
the distributor's Windows code-signing certificate.

Location estimates may disagree. Choose a provider in the map selector to view
its estimate. Provider agreement does not verify the actual device location.
Network ownership and reverse-DNS names are clues, not a confirmed address.

Version 1.2 includes a Public network details panel with provider-reported
VPN/proxy/Tor and other indicators, public registration contacts and dates,
observed routing information, and JSON report download. Missing indicators
are Unknown, not No. Registry contacts are public network-operation contacts,
not the person using the address. External reputation links are provided for
manual research; their detailed report histories are not automatically checked.

Additional queries send the entered IP to api.ipapi.is, rdap.org (which redirects
to the appropriate regional registry), and stat.ripe.net. Internet access and
provider availability/quotas affect these features. No API keys are embedded.
The app cannot retrieve Windows usernames, operating systems, files, passwords,
device models, or MAC addresses from a public IP alone.
